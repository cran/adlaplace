Introduction

This vignette applies the approximate maximum influence perturbation (AMIP) of Broderick, Giordano, and Meager in two settings. After fitting, outer parameters (beta, theta) are held at the MLE and only the inner random effects gamma are allowed to move. Package helpers phi_gamma(), influence_scores(), amip_set(), and ad_pack_drop() cover the shared pipeline: the fit-time observation tapes supply the inner Hessian \(H\); per-unit scores use streaming one-unit observation gradients (grad_obs_units) so scores do not require holding an identity shard pack.

The first example is the London case-crossover model: the most influential strata for flipping the PM10 effect at exposure 80. The second is the MASS bacteria Bernoulli GLMM: the most influential swabs for flipping the sign of the drug-versus-placebo treatment effect. In both cases an inner optimization with those units removed confirms the linear approximation, and a full refit on the reduced data is compared to the original fit.

Case-crossover: PM10 at 80

Same London daily mortality / PM10 specification as the case-crossover vignette. Abbreviated knits use 2003 only.

data("london", package = "adlaplace")

  london <- london[london$year == 2003, ]

cc_formula <- dirichlet_multinom(
  all,
  by = c("year", "month", "dow"),
  init = 0.02

  pm10,
  p = 2,
  knots = seq(0, 100, by = 10),
  ref_value = 40,
  init = 0.001
) + iwp(
  tmean,
  p = 3,
  knots = seq(-2, 30, by = 2),
  init = 0.001,
  ref_value = 20
)

Quantity of interest and influence scores

The PM10 smooth is centered at ref_value = 40, so the effect at 80 is a nontrivial linear functional \(\phi(\gamma) = a^\top\gamma\) of the IWP and random-polynomial coefficients. influence_scores() freezes the outer MLE, re-optimizes \(\gamma\) on the fit pack (for \(H\)), and streams one-unit observation gradients to form \(\psi_s = -v^\top g_s\).

Confirm by dropping nominated strata

ad_pack_drop() retapes the likelihood without the Approximate Most Influential Set (filtering the fit’s coarse observation shards). Keep the outer MLE fixed and re-optimize gamma. The resulting change in \(\phi(80)\) is an exact finite-sample lower bound on the worst-case strata-removal effect (Broderick et al.).

phi_from_gamma <- function(gamma) {
  sum(a * as.numeric(gamma))
}

pm_curve <- function(gamma, grid = seq(0, 100, by = 2)) {
  new_grid <- data.frame(pm10 = grid)
  design_list <- lapply(pm_terms, design, data = new_grid)
  design_list <- Filter(Negate(is.null), design_list)
  D <- as.matrix(do.call(cbind, design_list))
  g <- as.numeric(gamma)
  names(g) <- gamma_lab
  list(x = grid, f = as.numeric(D %*% g[colnames(D)]))
}

curve0 <- pm_curve(gamma_hat)

if (!length(drop_idx)) {
  phi_drop <- NA_real_
  curve1 <- NULL
  message("No strata dropped; skipping confirmation retape.")
} else {
  af_drop <- ad_pack_drop(fit, drop_idx, num_threads = vignette_num_threads)
  io_drop <- inner_opt(
    parameters = as.numeric(fit$par_info$mle_internal),
    gamma = gamma_hat,
    ad_pack = af_drop,
    control = list(report.level = 0, report.freq = 0),
    deriv = FALSE,
    return_hessians = FALSE,
    verbose = FALSE
  )
  gamma_drop <- as.numeric(io_drop$inner_opt$solution)
  phi_drop <- phi_from_gamma(gamma_drop)
  curve1 <- pm_curve(gamma_drop)
}

c(
  phi_full = phi_hat,
  phi_dropped = phi_drop,
  actual_change = if (is.finite(phi_drop)) phi_drop - phi_hat else NA_real_,
  approx_change = if (length(drop_idx)) amip_change else NA_real_
)
#>      phi_full   phi_dropped actual_change approx_change 
#>   0.011166203  -0.001367806  -0.012534009  -0.011507652

Bacteria: sign-flip of the drug effect

The MASS bacteria data are 220 swabs on 50 children, with a three-level treatment (placebo, drug, drug+) and follow-up week. Treatment coefficients are placed in the inner field with known-SD Gaussian priors, so the drug-versus-placebo contrast is a coordinate of \(\gamma\) and the same inner AMIP applies. There is no ELGM map, so grad_obs_units scores individual swabs. (Summing scores to children is not enough to flip this contrast under the linear approximation.)

Notes

  • Case-crossover removal units are strata (year–month–day-of-week matched sets), not individual calendar days. Bacteria removal units are swabs (rows of the observation vector). Use n_obs_units() for the domain size.
  • The inner confirmation keeps outer parameters at the original MLE: that is sensitivity of \(\hat\gamma(\beta,\theta)\), not a refit of smoothness or overdispersion. The refit chunks re-estimate the full outer MLE on the reduced data.
  • Scores use streaming one-unit observation tapes (grad_obs_units inside influence_scores); \(H\) comes from the fit pack via inner_opt. Confirmation retapes a filtered likelihood with ad_pack_drop().
  • The bacteria example needs MASS. Those chunks are skipped when it is not installed.

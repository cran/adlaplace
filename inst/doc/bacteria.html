This vignette fits a Bayesian Bernoulli GLMM to the bacteria data from MASS, then integrates the Laplace-approximate marginal posterior for the random-effect standard deviation with aghq. The formula interface hides the AD / Laplace details: known-SD Gaussian priors on the former fixed effects, an exponential prior on the child-level SD, and one call to adlaplace() followed by aghq::aghq().

Data

data(bacteria, package = "MASS")
bacteria$present <- as.integer(bacteria$y == "y")

There are 220 swabs on 50 children (ID), a three-level treatment, and follow-up week at 0, 2, 4, 6, and 11.

rate <- aggregate(present ~ week + trt, data = bacteria, FUN = mean)

Model

The hierarchical model is

\[ \begin{aligned} y_{ij} &\sim \mathrm{Bernoulli}(p_{ij}), \\ \mathrm{logit}(p_{ij}) &= \alpha + \mathbf{x}_{ij}^\top\boldsymbol{\beta} + u_i, \\ \alpha, \beta_k &\sim N(0, 10^2), \\ u_i &\sim N(0, \sigma^2), \\ \sigma &\sim \mathrm{Exp}(\text{median} = 1). \end{aligned} \]

Moving the intercept, treatment, and week coefficients into the random-effect block with known SDs leaves a one-dimensional outer parameter (\(\log\sigma\)). Nested Laplace then integrates the latent field; AGHQ integrates \(\log\sigma\).

fit <- adlaplace(
  binom(present) ~
    intercept(sd = 10) +
    linear(trt, sd = 10) +
    linear(week, sd = 10) +
    iid(ID, init = 1) +
    prior(theta = 0, dist = "exp", median = 1),
  data = bacteria
)
summary(fit)

intercept(sd = 10), linear(trt, sd = 10), and linear(week, sd = 10) are known-SD Gaussian priors (no estimated \(\theta\)). iid(ID) supplies the child intercepts and their SD. prior(theta = 0, ...) puts an exponential prior on the first (0-based) theta — here the only one, ID_iid.

adlaplace() returns the MAP of \(\log\sigma\) under that prior. The outer vector has length one:

coef(fit)
#>   ID_iid 
#> 1.292995
nrow(fit$par_info)
#> [1] 1

Adaptive Gauss–Hermite quadrature

aghq_ff(fit) wraps the same Laplace objective used by adlaplace() for aghq. Use negate = TRUE because the wrappers return the negated log posterior.

ff <- aghq_ff(fit)
quad <- aghq::aghq(
  ff = ff,
  k = aghq_k,
  startingvalue = fit$par_info$mle_internal,
  control = aghq::default_control(negate = TRUE)

Posterior of \(\sigma\)

naw <- quad$normalized_posterior$nodesandweights
nodes <- as.numeric(naw[[1L]])
w <- exp(as.numeric(naw$logpost_normalized))
w <- w / sum(w)

Normalized AGHQ nodes for the child-level SD.

The nested approximation for a coefficient \(\gamma_j\) (intercept, treatment, week) is a mixture of normals: at AGHQ node \(\theta_k = \log\sigma_k\) with weight \(w_k\),

\[ \gamma_j \mid \theta_k, y \;\approx\; N\bigl(\hat\gamma_j(\theta_k),\; [H(\theta_k)^{-1}]_{jj}\bigr), \qquad p(\gamma_j \mid y) \;\approx\; \sum_k w_k\, \varphi\bigl(\gamma_j;\, \hat\gamma_j(\theta_k),\, [H(\theta_k)^{-1}]_{jj}\bigr). \]

gamma_info <- fit$model_data$term_data$info$gamma
coef_idx <- which(gamma_info$model != "iid")
coef_lab <- gamma_info$gamma_label[coef_idx]
ctrl_mix <- list(
  maxit = if (vignette_full) 100L else 20L,
  report.level = 0,
  report.freq = 0
)

mix_mean <- matrix(NA_real_, length(nodes), length(coef_idx))
mix_sd <- mix_mean
colnames(mix_mean) <- colnames(mix_sd) <- coef_lab
gamma_start <- fit$gamma

for (k in seq_along(nodes)) {
  ll <- log_lik_laplace(
    x = nodes[[k]],
    ad_pack = fit$ad_pack,
    config = fit$config,
    gamma = gamma_start,
    deriv = FALSE,
    control = ctrl_mix
  )
  gamma_start <- ll$inner_opt$solution
  names(gamma_start) <- names(fit$gamma)
  half <- laplace_half_H_inv(ll)
  mix_mean[k, ] <- gamma_start[coef_lab]
  mix_sd[k, ] <- sqrt(Matrix::rowSums(half[coef_idx, , drop = FALSE]^2))
}

mix_dnorm <- function(x, mean, sd) {
  dens <- vapply(
    seq_along(w),
    function(k) stats::dnorm(x, mean[[k]], sd[[k]]),
    numeric(length(x))
  )
  as.numeric(dens %*% w)
}

mix_qnorm <- function(p, mean, sd) {
  lo <- min(mean - 8 * sd)
  hi <- max(mean + 8 * sd)
  stats::uniroot(
    function(q) sum(w * stats::pnorm(q, mean, sd)) - p,
    lower = lo,
    upper = hi
  )$root
}

pretty_coef <- function(lab) {
  if (identical(lab, "intercept")) {
    return("intercept")
  }
  if (startsWith(lab, "trt_linear_")) {
    lev <- sub("^trt_linear_trt", "", lab)
    return(paste0("trt: ", lev, " vs placebo"))
  }
  if (startsWith(lab, "week_linear_")) {
    return("week")
  }
  lab
}

Posterior quantiles invert the mixture CDF. The child-level SD uses the AGHQ nodes (a discrete mixture on \(\log\sigma\)). Child-specific IID intercepts are omitted.

probs <- c(0.025, 0.5, 0.975)
q_coef <- t(vapply(
  coef_lab,
  function(lab) {
    vapply(probs, mix_qnorm, numeric(1), mean = mix_mean[, lab], sd = mix_sd[, lab])
  },
  numeric(length(probs))
))
sigma_q <- vapply(probs, function(p) {
  o <- order(sigma)
  cw <- cumsum(w[o])
  sigma[o][which(cw >= p)[1L]]
}, numeric(1))

post_q <- data.frame(

Fitted probabilities and child effects

Subject-specific fitted probabilities at the MAP use fitted(fit) (modes of all random effects, including the former fixed effects).

bacteria$p_hat <- plogis(fitted(fit))
fit_rate <- aggregate(p_hat ~ week + trt, data = bacteria, FUN = mean)

plot(
  p_hat ~ week, data = fit_rate, type = "n",
  ylim = c(0, 1), ylab = "probability present"
)
for (g in levels(bacteria$trt)) {
  d <- fit_rate[fit_rate$trt == g, ]
